swap_horiz 값 변환 규칙 —

위에서부터 순서대로 검사해 처음 일치한 규칙 1개만 적용합니다. 일치하는 규칙이 없으면 원본 값을 그대로 출력합니다. 변환값을 비워 두면 빈 칸으로 출력됩니다.

info 변환 규칙 안내

1. 행 변환

  • 원본 시트의 헤더 행 아래 데이터를 순서 그대로 1:1로 옮깁니다 (정렬·필터 없음).
  • 모든 셀이 비어 있는 행(완전 빈 행)만 제외됩니다.
  • 값은 가공 없이 그대로 복사되며, 날짜 셀은 m/d 표시 형식의 날짜 값으로 유지됩니다.

2. 컬럼 매핑

  • 결과 컬럼은 이름 변경 · 추가 · 삭제 · 순서 변경(↑↓) · 정렬 · 너비를 자유롭게 바꿀 수 있습니다.
  • 값 유형: 원본 컬럼(원본 값을 그대로 복사) / 고정값(모든 행에 같은 값 입력, 숫자만 입력하면 숫자로 저장).
  • 원본 컬럼은 열 위치 + 헤더 이름으로 기억합니다. 같은 이름의 컬럼(예: 비고 W / 비고 AG)도 구분되며, 시트나 헤더 행을 바꾸면 같은 컬럼을 다시 찾습니다.
  • 기본값(0922 포맷): 설비명 ← 설비명, UNIT 명 ← UNIT 명(F), 비고 ← 두 번째 비고(AG). [기본값 복원]으로 언제든 되돌릴 수 있습니다.
  • 원본 컬럼을 찾지 못하면 "사용 안 함"(빈 값 출력)으로 두고 경고로 표시합니다.
  • 값 변환(⇄ 버튼): 조건(값 일치 / 날짜 형식 / 빈 값 / 그 외 값)에 따라 다른 값으로 바꿔 출력합니다.

3. 카운트 (잔건 시트 상단)

  • 전체 개조수량 (가로형, I/F 대상 "미대상" 행 제외): 총 수량 = No 값이 있는 행 · 완료 · 진행중 = 행마다 Online 날짜 있으면 완료, 없으면(빈 값 · 글자) 진행중, 단 전조투입장 (각인기) 행은 그 블록 기준(I/F 대상 날짜) · 진행률 = 완료 ÷ 총 수량
  • MES (실적) (세로형): I/F 대상이 "미대상" · "F/S대상"이 아닌 모든 행(날짜 · 빈 값 · 그 외, "Event" 항목이 있는 행 제외)의 전체수량 / 완료 = I/F 대상에 날짜 있음 / 진행중 = I/F 대상에 날짜 없음 (Online 컬럼은 보지 않음, 비율 = 항목 ÷ 전체수량)
  • MES (Event) (세로형, MES (실적) 오른쪽): I/F 대상 값을 쉼표(,)로 나눈 항목에 "Event"가 있는 행의 전체수량 / 완료 = 날짜 항목도 있음 (예: 10/02,Event) / 진행중 = 날짜 항목 없음 (예: Event)
  • FactorySight (품질) (세로형): I/F 대상 = "F/S대상"인 행의 전체수량 / 완료 / 진행중 ("미대상"인 행은 MES · FactorySight 어디에도 집계하지 않음)
  • 전조투입장 (각인기) (세로형): 설비명 = "UV각인기I/F"인 행(I/F 대상 "미대상" 제외)의 전체수량 / 완료 = I/F 대상 항목에 날짜 있음 / 진행중 = 날짜 없음 (MES (Event)와 같은 기준, Online 컬럼은 보지 않음)
  • BCR (실적/품질) (그룹별 표, 공장별 행 + 합계): 설비명 = "조립 BCR" · "완성 BCR" · "전조투입 BCR"인 행에서 PLC 수량 = 행 수 · BCR 수량 = Data수량 합계 · 완료 = Online 수량 합계 · 진행중 = BCR 수량 − 완료 · 진행률 = 완료 ÷ BCR 수량. 공장은 원본 "공장" 컬럼(숨김) 기준입니다.
  • Data수량 · Online 수량은 숨김 컬럼(눈 아이콘)이라 결과 시트에는 출력되지 않고 카운트에만 쓰입니다. 숫자가 아닌 값은 0으로 더합니다.
  • 블록명이 같은 항목이 연속되면 한 블록으로 묶입니다. 가로형 블록은 한 줄을 모두 쓰고, 세로형 블록은 두 개씩 나란히 놓이며, 카운트 아래에 진행중(잔 건 수) 칸과 잔 건 리스트(전체 개조수량 진행중과 같은 행 — 진행중 칸 = 전체 개조수량 진행중)가 이어집니다. 조건을 여러 개 넣으면 모두 만족하는 행만 셉니다.
  • 카운트는 값 변환이 적용된 결과 값 기준으로 계산합니다.
  • 블록별 시트: 블록명이 있는 세로형 블록마다 시트를 만들어 그 블록 전체수량에 해당하는 행을 모두 출력합니다. 컬럼은 No · 공정명 · 설비명 · UNIT 명 · IP · Online · 상태("완료" / "진행중")이고, No는 시트마다 1부터 다시 매깁니다. 시트 이름의 / 등 엑셀에서 쓸 수 없는 글자는 · 로 바뀝니다. BCR은 행마다 Online 수량 ≥ Data수량이면 완료, 아니면 진행중입니다. BCR 시트에는 UNIT 명 뒤에 BCR 수량(Data수량) 컬럼이 추가되고, 아래에 잔건 표(No · 공정명(설비명) · 내용 = 비고를 "," 로 나눈 두 번째 값)가 붙습니다.
  • 규칙이 참조하는 결과 컬럼을 삭제하면 해당 규칙에 경고가 표시되고, 기준 컬럼을 다시 고르기 전까지 변환이 실행되지 않습니다.
결과 파일은 종합(설비 리스트) · 잔건(카운트 현황판 + 잔 건 리스트) · 블록별 시트(MES (실적) · MES (Event) · FactorySight (품질) · 전조투입장 (각인기) · BCR (실적·품질))를 담은 새 xlsx 파일로 생성되며, 원본 파일은 변경되지 않습니다.
